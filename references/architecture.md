# 學習能量軌跡 AI 助教：系統架構、資料表規格與資安設計參考

## 1. 系統整體架構 (`index.html` + `Code.gs`)

* **前端 (`index.html`)**：
  * 單頁式無框架響應式應用（原生 HTML5 / CSS3 / Canvas 2D + 3D CSS Transform），同時支援 **GitHub Pages 靜態託管（透過 `fetch` 呼叫 GAS JSON API）** 與 **Google Apps Script `HtmlService` 原生嵌入（`google.script.run`）** 雙棲運作。
  * **五大核心視圖**：
    1. **繳交作品 (`#view-submit`)**：免登入填寫班級、座號、姓名與作業項目，支援 1~4 張多頁照片自動垂直拼接成單張高解析長圖、勾選「✨ 這是訂正重交作品（挑戰更高分）」自動比對前次收據、雙軌五維素養雷達圖、藝術創作三分構圖線／視覺重心熱區／主調色票疊圖診斷、以及 **58mm 實體創客胸章工作坊**（圓形互動取景、300DPI 單張印刷檔、A4 1:1 六宮格刀模單、A4 特級認證證書、學習歷程卡匯出）。
    2. **我的能量軌跡 (`#view-trajectory`)**：學生憑本人任一張電子收據編號（UUID），查詢整學期跨作業成長曲線、累計躍升分數光環、最近三次五維度雷達疊圖比較、歷次 AI 與教師正式評語、以及個人榮譽胸章收藏櫃。
    3. **極光成果星空 (`#view-gallery`)**：深空極光玻璃擬態藝廊，支援 **班級、作業項目、作品類型、關鍵字、排序方式（最新／最高分）五維度即時檢索整理**，姓名自動去識別化遮罩（如 `林○光`），點擊卡片可開啟 **360° 3D 立體金屬胸章互動鑑賞視窗**。
    4. **教師使用手冊 (`#view-manual`)**：內建一至六章完整單排並陳（`.tm-nav` 6 欄 Grid）之互動式教學指南，支援一鍵展開全部章節與 A4 紙本手冊列印。
    5. **教師管理後台 (`#view-admin`)**：含 **班級學力五維診斷雷達與共同盲點分析**、單筆審核調分與評語改寫、勾選作品 **一鍵批次審查通過（達標核發胸章）**、全班胸章 A4 六宮格批次排版印刷、**跨科作業項目與自訂 Rubrics 規準管理**、星空藝廊一鍵去重修復、以及 **10 秒一鍵匯出 Google Docs 全班學習能量成果冊**。
* **後端 (`Code.gs`)**：
  * Google Apps Script Web App (`doGet` / `doPost`)，整合 `SpreadsheetApp`、`DriveApp`、`DocumentApp`、`PropertiesService`、`CacheService` 與 `LockService`。
  * 串接 Google Gemini 多模態 REST API（預設優先使用 `gemini-2.5-pro`，若遇配額或延遲自動備援至 `gemini-2.5-flash` / `gemini-2.0-flash`）。

## 2. Google 試算表資料庫 Schema（3 大核心工作表）

系統首次啟動時會自動建立試算表「**學習能量軌跡AI彙整總表**」並格式化以下三張工作表：

| 工作表名稱 | 用途 | 欄位結構 |
| :--- | :--- | :--- |
| `能量軌跡總表` | 全校學生作品、AI 五維評量、教師審核與胸章主資料表（**22 欄**） | `0:繳交時間`、`1:班級`、`2:座號`、`3:姓名`、`4:作業項目`、`5:作品類型`、`6:檔案名稱`、`7:檔案連結`、`8:主題／稱號`、`9:探究關鍵詞`、`10:歷程摘要／畫面描述`、`11:AI 評語草稿`、`12:延伸建議`、`13:SDGs／創作主題`、`14:能量總分`、`15:維度分數(JSON)`、`16:收據UUID`、`17:教師審核狀態`、`18:胸章狀態`、`19:胸章檔案連結`、`20:教師評語`、`21:胸章檔案ID` |
| `星空藝廊` | 獲核發胸章並公開展示於「極光成果星空」之精選索引表（**9 欄**） | `發放時間`、`收據UUID`、`班級`、`學生（遮罩）`、`作品類型`、`主題／稱號`、`能量總分`、`胸章檔案ID`、`縮圖Base64` |
| `系統設定` | 教師可直接於試算表修改之系統參數與金鑰表（**3 欄**） | `設定項目(Key)`、`設定內容(Value)`、`說明`（含 `GEMINI_API_KEY`、`ADMIN_PASSWORD`、`ASSIGNMENTS`、`BADGE_APPROVAL`、`BADGE_THRESHOLD`、`GALLERY_PUBLIC`、`DAILY_LIMIT`、`ACTIVE_MODEL`、`ASSIGNMENT_RULES`） |

## 3. 雙軌五維度素養評量規準與訂正閉環

1. **探究筆記五維度 (`NOTE_DIMS_`，各 0~20 分，滿分 100 分)**：
   * `focus`（主題聚焦）：核心問題意識與研究目標清晰度。
   * `depth`（探究深度）：資料蒐集、實驗觀察或推論深度。
   * `structure`（資料條理）：心智圖、表格、邏輯層次與結構組織。
   * `insight`（反思洞見）：個人觀點、生活連結、誤區訂正或跨域遷移。
   * `presentation`（視覺呈現）：字跡工整度、圖文版面配置與重點標記。
2. **藝術創作五維度 (`ART_DIMS_`，加權計算滿分 100 分)**：
   * `themeScore`（主題語意與創意，權重 **35%**）
   * `compScore`（結構重心與構圖，權重 **20%**）
   * `colorScore`（色彩豐富與和諧，權重 **15%**）
   * `lightScore`（光影明暗與立體感，權重 **15%**）
   * `detailScore`（筆觸質感與細節完成度，權重 **15%**）
3. **跨科自訂 Rubrics 動態注入 (`ASSIGNMENT_RULES`)**：
   * 老師可為每個作業項目指定「學科領域視角（國、英、數、自、社、跨領域、藝術、胸章）」與「專屬評分規準文字」，後端自動將該作業規準注入 Gemini 系統提示詞。
4. **訂正重交躍升閉環 (`isRevision` / `prevReceipt`)**：
   * 學生勾選「訂正重交」時，系統自動檢索同學生、同作業之前次繳交紀錄，將前次分數與 AI 建議一併提供給模型進行前後比對，並在結果頁頒發「🚀 訂正大進步：上次 X 分 ➔ 本次 Y 分（成長 +Z 分！）」激勵橫幅。

## 4. 58mm 實體創客胸章三規刀模規格

* **畫布解析度**：`1000 × 1000 px`（對應 70mm 外出血圈達 **362 DPI** 印刷品質）。
* **三規同心圓比例**：
  * **外圈裁切出血圓（70mm）**：半徑 `R = 450 px`（虛線導引，供圓形裁刀切割）。
  * **中圈成品折邊圓（58mm）**：半徑 `R = 373 px`（胸章正表面邊界，70mm 與 58mm 之間為包邊折入鋁殼背面區域）。
  * **內圈視覺安全圓（50mm）**：半徑 `R = 321 px`（所有分數、主題稱號、班級姓名皆透過雙層留白自動內縮於安全圓內，確保壓製成品絕不切字）。

## 5. 資安、防偽與個資保護準則

1. **二進位檔頭防偽 (`sniffMime_`)**：
   * 後端不信任副檔名，直接檢驗二進位 Magic Bytes（JPEG `FF D8 FF`、PNG `89 50 4E 47`、PDF `%PDF-`），攔截偽造檔案與超過 10MB 之酬載。
2. **UUID v4 電子收據與去識別化查詢**：
   * 學生免帳號登入，每次繳交核發唯一 UUID v4 收據；查詢個人能量軌跡時，必須通過「班級＋座號＋姓名＋本人任一張有效收據 UUID」雙重核驗，防止窺探他人成績。
   * 公開「極光成果星空」全面執行姓名中間字遮罩（`maskName_`），且不暴露原始作業大圖連結。
3. **試算表公式注入防護 (`sanitizeCell_`)**：
   * 寫入 Google Sheets 前自動為 `=`, `+`, `-`, `@` 開頭之字串加上單引號前綴，徹底阻絕 CSV / Sheet Formula Injection。
4. **教師後台 Session Token 與防暴力破解**：
   * 教師登入採用 `Utilities.computeHmacSha256Signature` 簽發具時效性之管理 Token，並以 `CacheService` 限制連續密碼錯誤次數；公開 API (`getPublicConfig`) 絕不回傳 `GEMINI_API_KEY` 明文、管理密碼或試算表私密網址。
